Getting around

The ship is the hotel. The pier is the trap. Price the pre-cruise night if your flight cannot miss the gangway.

No rental

  • Fly in the day before if you cannot miss the ship. That hotel is a line, not a maybe
  • Port parking only if you drove. Rideshare to PortMiami / Port Canaveral / Port Everglades is often cheaper than a week of parking
  • In port: walk or a pre-negotiated taxi. The “tour” on the pier is the overrun

Where to eat

The dining room is already in the fare. Main dining most nights. One specialty night only if you already priced it.

Budget

  • Breakfast / lunch: buffet or dining room already in the fare
  • Dinner main dining room every night on Budget
  • Drinks pay-as-you-go; run the break-even before a package
  • Room-service fees add up use it as a backup, not breakfast

Mid-range

  • Main dining room most nights that is the product
  • One specialty night (Cagney’s / Chops / Teppanyaki class) if you have room in the budget for it
  • Drink package only after you run the break-even
  • Room service fees add up use it as a backup, not breakfast

Splurge

  • Dining room + one or two specialty reservations (Italian / steak / sushi)
  • Chef’s table or a specialty brunch only if you're spending more
  • Unlimited adult drinks + kids soda are in this Splurge plan still run the math
  • Specialty is only if you're spending more, not a nightly habit

Things to do

Sea days are the product. One independent port walk plus one ship excursion — not three dock tours.

Free / cheap

  • Sea days are the product walk the deck, skip the spa menu (free)
  • One independent port walk, not a dock kiosk (free / cheap)
  • Ship shows and the pool already in the fare (free)

Paid — pick one

  • One ship excursion + one independent port day (ticketed / free)
  • Drink package only after the break-even math (optional)
  • Snorkel or beach-break on one island, not three (ticketed)

One port, two ways to spend it

Book before you go

  • Cabin class and the sailing date — check holiday weeks first
  • Pre-cruise hotel if the inbound flight cannot miss the gangway
  • Drink package only after you run the break-even
  • One ship excursion if you want it — independent walks for the rest

Hidden costs

  • Automatic gratuities (age 2+) — not buried in the fare
  • Drink package you tapped yes on
  • Specialty and room-service fees
  • Dock kiosk “tours” and bottled water
  • Flights to Florida ports plus a pre-cruise hotel
  • Port parking for the week if you drove

Skip this

  • Tapping yes on the drink package — À-la-carte wins if you are not a five-drink day. Run the break-even.
  • Three dock tours — One independent walk plus one ship excursion.
  • Specialty every night — The dining room is the product. One treat night.

Keep the number honest

Top money-saving tips

  1. Run the drink-package break-even before you tap yes. À-la-carte wins if you are not a five-drink day.
  2. Interior or obstructed oceanview on Budget. You bought the itinerary and the deck, not the porthole.
  3. Main dining room every night on Budget. One specialty night only if you already priced it.
  4. One independent port walk plus one ship excursion — not three dock tours.
  5. Automatic gratuities are a line (age 2+). They are not optional math and they are not buried in the fare.
  6. Shoulder weeks (early May, early September) cut the cabin and the air to Florida ports.
  7. Kids soda is often the only package that wins on a short sailing. The latte habit is not a package.
  8. Room-service fees add up — backup, not breakfast. The buffet is already in the fare.
